# أرض الغسق — نسخة يونيتي: كيف تشغّلها خطوة بخطوة

هذا الدليل لمن لم يستعمل يونيتي من قبل. اتبع الخطوات بالترتيب ولا تتخطَّ شيئاً.

> **مهم:** يونيتي يعمل على **كمبيوتر** (ويندوز أو ماك) فقط، لا على الجوال. الجوال يستقبل اللعبة في النهاية كملف APK.

---

## ما تحتاجه قبل البدء

| الشيء | المطلوب |
|---|---|
| الجهاز | كمبيوتر ويندوز 10 أو 11 (64 بت) أو ماك |
| الذاكرة | 8 جيجا رام على الأقل (16 أفضل) |
| المساحة | 25 جيجا فارغة على القرص |
| الإنترنت | نحو 6 إلى 8 جيجا للتنزيل (يونيتي + أدوات أندرويد + المشروع) |
| حساب | حساب يونيتي (Personal، مجاني) — عندك واحد مفعّل |

---

## الخطوة 1: نزّل المشروع المضغوط

1. افتح صفحة الإصدارات:
   **https://github.com/khalilo-cs/Duskwell-/releases**
2. ابحث عن الإصدار **Duskwell Unity** ونزّل الملف **`Duskwell-Unity-Project.zip`** (حجمه نحو 170 ميجا).
3. إن لم تجده هناك: افتح **https://github.com/khalilo-cs/Duskwell-/actions/workflows/unity-pack.yml** ← اضغط على أحدث تشغيل (أعلى القائمة، علامته ✅) ← انزل إلى **Artifacts** ← اضغط **duskwell-unity** للتنزيل (يلزم تسجيل الدخول إلى GitHub).

## الخطوة 2: فكّ الضغط في مسار قصير

1. أنشئ مجلداً اسمه **`Duskwell`** مباشرة في القرص `C:` (أي `C:\Duskwell`).
   - **لا تضعه** في سطح المكتب ولا في مجلد اسمه عربي أو فيه مسافات؛ يونيتي ينزعج من المسارات الطويلة والأحرف غير الإنجليزية.
2. اضغط بالزر الأيمن على الملف المضغوط ← **Extract All** (استخراج الكل) ← اختر `C:\Duskwell` ← **Extract**.
3. تأكّد أن عندك الآن المجلد **`C:\Duskwell\duskwell-unity`** وفي داخله مباشرة هذه المجلدات:
   `Assets` و `Packages` و `ProjectSettings` وهذا الملف `START_HERE.md`.
   - إن وجدت مجلداً داخل مجلد بنفس الاسم، فالمجلد الصحيح هو الذي يحتوي `Assets` مباشرة.

## الخطوة 3: ثبّت Unity Hub

1. افتح **https://unity.com/download** ← اضغط **Download for Windows** (أو Mac).
2. شغّل الملف الذي نزل ← **I Agree** ← **Install** ← **Finish**.
3. افتح **Unity Hub** ← **Sign in** ← ادخل بحساب يونيتي الذي فعّلته.
4. إن سألك عن الترخيص: **Manage licenses** ← **Add** ← **Get a free personal license** (عندك واحد مفعّل غالباً، فقد لا يسألك).

## الخطوة 4: ثبّت محرّر يونيتي بالنسخة الصحيحة مع أدوات أندرويد

المشروع مبني على **Unity 2022.3 LTS** (النسخة المسجّلة فيه `2022.3.62f1`).

1. في Unity Hub اضغط **Installs** (يسار) ← **Install Editor** (أعلى يمين).
2. في تبويب **Official releases** اختر أحدث نسخة تبدأ بـ **2022.3** وبجانبها كلمة **LTS** ← **Install**.
   - إن أردت النسخة نفسها بالضبط: افتح **https://unity.com/releases/editor/archive** ← **2022** ← ابحث عن **2022.3.62f1** ← زر **Unity Hub** بجانبها.
3. تظهر قائمة الإضافات (Modules). **علّم** هذه بالضبط:
   - ✅ **Android Build Support**
     - ✅ **OpenJDK**
     - ✅ **Android SDK & NDK Tools**
   - (اختياري: أزل علامة **Microsoft Visual Studio Community** لتوفير المساحة.)
4. **Continue** ← وافق على رخصة أندرويد (علّم **I have read and agree**) ← **Install**.
5. انتظر حتى ينتهي التنزيل والتثبيت (قد يستغرق من 20 دقيقة إلى ساعة حسب الإنترنت).

## الخطوة 5: أضف المشروع إلى Unity Hub وافتحه

1. في Unity Hub اضغط **Projects** (يسار).
2. اضغط السهم ▼ بجانب زر **Add** ← **Add project from disk**.
3. اختر المجلد **`C:\Duskwell\duskwell-unity`** (المجلد الذي فيه `Assets`) ← **Open** (أو Add Project).
4. يظهر المشروع باسم **duskwell-unity** في القائمة. إن ظهر بجانبه تحذير ⚠ عن نسخة المحرّر:
   اضغط على رقم النسخة بجانبه ← اختر نسخة **2022.3** التي ثبّتها ← إن سألك **Change Editor version?** اضغط **Continue** / **Change Version**.
5. اضغط على اسم المشروع لفتحه.

## الخطوة 6: انتظر الفتح الأول

- الفتح الأول **طويل** (من 10 إلى 40 دقيقة): يونيتي يستورد نحو 3500 ملف من الصور والأصوات. لا تغلقه حتى لو بدا متوقفاً.
- إن ظهرت نافذة **Enter Safe Mode?**:
  اضغط **Enter Safe Mode** ← من القائمة **Window ← General ← Console** ← صوّر الأسطر الحمراء وأرسلها لي لأصلحها.
- عند انتهاء الاستيراد تظهر واجهة يونيتي كاملة.

## الخطوة 7: العب داخل يونيتي

1. في أعلى المنتصف تجد زر التشغيل **▶ (Play)**. **لا تحتاج فتح أي مشهد**؛ اللعبة تبني نفسها بالكود عند الضغط على Play.
2. قبل الضغط: اذهب إلى تبويب **Game** ← في أعلاه قائمة مكتوب فيها **Free Aspect** ← اختر **16:9** أو **Full HD (1920x1080)**.
3. اضغط **▶**. تظهر شاشة العنوان المرسومة ← اضغط **رحلة جديدة** ← تبدأ المقدّمة المرسومة (اضغط أو Z أو Enter للتقدّم، أو **تخطٍّ** للتخطي).
4. **اضغط داخل نافذة Game مرة واحدة** حتى تستقبل لوحة المفاتيح، ثم العب:

| الزر | ماذا يفعل |
|---|---|
| ← → | الحركة |
| Z أو Space | القفز (اضغط مطوّلاً لقفزة أعلى) |
| X | ضربة السيف (تكسر الجدران الهشّة بثلاث ضربات وتحرّك الروافع) |
| C | الاندفاع (بعد هزيمة الحارس الحجري) |
| F (ضغطة سريعة) | كرة روح |
| F (ضغطة مطوّلة) | الشفاء (يحتاج روحاً؛ الروح تمتلئ بضرب الوحوش) |
| ↑ | التحدّث مع الناس، الجلوس على المقعد (يحفظ ويشفي)، قراءة اللوحات |
| ↓ + X في الهواء | الانقضاض (بعد هزيمة أمّ الأبواغ) |
| Z أو Enter أو الضغط بالفأرة | تقدّم الحوار والقصة |
| ↑ + F (ضغطة سريعة) | تعويذة **صرخة الغسق**: عمود ضوء فوقك (يعلّمها الساحر بعد 4 شظايا) |
| ↓ + F في الهواء | تعويذة **سقوط النجم** (يعلّمها الساحر بعد 8 شظايا) |
| C مطوّلاً على الأرض | **الاندفاع الخارق** بعد أن تناله |
| X مطوّلاً ثم أفلته | **فنون النصل** بعد تطويره: الضربة العظمى، أو ضربة الاندفاع إن أفلته وأنت تندفع، أو الإعصار إن أفلته في الهواء |
| Esc أو P أو Tab أو I (أو زر ☰ أعلى يمين الشاشة) | القائمة بأربع صفحات: **الخريطة** و**الحقيبة** و**التمائم** و**دفتر الصيّاد**؛ تنقّل بينها بـ ← → |

5. لإيقاف اللعب اضغط **▶** مرة أخرى.
6. أول ما تفعله في اللعبة: امشِ في القرية وتحدّث مع **الشيخ أوراد** (↑ قربه).
7. **النصل الواحد وتطويره:** لك سلاح واحد فقط، **نصل الجذوة**، وله خمس مراحل يصنعها الحدّاد **قَرن** في القرية. كل مرحلة تشترط أشياء معاً:
   **حجر الجذوة الشاحب** (يتركه كل حارس تعويذة وكل حارس طريق تهزمه)، وجيو، وشظايا القنديل، وعدد من المخلوقات المهزومة، وللمرحلتين الأخيرتين حرّاس الطرق.
   تحدّث مع قَرن ← **ماذا يحتاج نصلي؟** لترى ما ينقصك (✓ و ✗)، أو افتح **الحقيبة** من قائمة الإيقاف.
8. **الظل:** إن سقطت يبقى ظلّك حيث سقطت ومعه كل الجيو. ارجع إليه واهزمه لتستعيده؛ إن سقطت قبل ذلك ضاع.
9. **الخريطة:** لا تُرسم منطقة على خريطتك إلا إذا اشتريت خريطتها من **الرحّالة** في تلك المنطقة (120 جيو) أو زرت غرفها. فيها المقاعد والناس والزعماء وموقعك. اضغط على منطقة لتكبيرها.
10. **التمائم:** تجدها في العالم أو تنالها من حرّاسها. لك عدد محدود من **الفتحات** (يزيد كلما جمعت شظايا)، وكل تميمة تأخذ فتحة أو أكثر. **تلبسها وتخلعها على المقعد فقط**، من صفحة التمائم.
11. **على الجوال:** اسحب زر الروح لأعلى لصرخة الغسق، ولأسفل لسقوط النجم.
12. **الوحوش** تهاجم بحركات خاصة: الاندفاع، والانقضاض من الجو، والبصق. وبعض الحرّاس الكبار لهم ضربات مميزة (زلزال، حلقة، قطع، أعمدة) ويغضبون عند نصف صحتهم.
13. **دفتر الصيّاد:** كل وحش تهزمه يُدوَّن في الدفتر بصورته المرسومة ووصفه، ويكتمل بعد عشرة منه. الزعماء يكتملون حين تهزمهم. ما لم تهزمه يبقى ظلاً أسود.
14. **فنون النصل:** كل مرحلة من النصل تعلّمك فنّاً: المشحوذ ← **الضربة العظمى**، المسقي ← **ضربة الاندفاع**، نصل الجمر ← **الإعصار**. اضغط X مطوّلاً حتى يتوهّج البطل ثم أفلته.
15. **السفر:** كل مقعد تجلس عليه يُحفظ. وأنت جالس على مقعد افتح الخريطة: المقاعد التي استرحت عليها تتوهّج، اضغط واحداً فتحملك فراشة القنديل إليه.
16. **ذكرى المعركة:** وأنت على مقعد، افتح **دفتر الصيّاد** واختر زعيماً هزمته ← **استدعِ ذكرى المعركة**: تنام وتقاتله من جديد في قاعته. لا تخسر فيها جيو ولا يبقى ظلّ، وتستيقظ على المقعد في الحالتين، ويُعلَّم الزعيم في الدفتر إن انتصرت.

## الخطوة 8: اصنع ملف APK للجوال

1. من القائمة العليا: **File ← Build Settings**.
2. في القائمة يسار النافذة اختر **Android** ← اضغط **Switch Platform** ← انتظر (قد يأخذ 10 إلى 30 دقيقة أول مرة) ← أغلق النافذة.
3. من القائمة العليا: **Duskwell ← Build Android APK**.
4. انتظر (البناء الأول من 10 إلى 30 دقيقة). عند النجاح تظهر رسالة فيها مكان الملف، ويفتح المجلد:
   **`C:\Duskwell\duskwell-unity\Build\duskwell-unity.apk`**
5. إن فشل البناء تظهر رسالة؛ افتح **Window ← General ← Console** وصوّر الأسطر الحمراء وأرسلها لي.

## الخطوة 9: ثبّت اللعبة على الجوال

1. انقل `duskwell-unity.apk` إلى الجوال (كابل USB، أو Google Drive، أو أرسله لنفسك على تيليجرام/واتساب كملف).
2. اضغط عليه في الجوال ← إن ظهر **تثبيت تطبيقات غير معروفة** اضغط **الإعدادات** ← فعّل **السماح من هذا المصدر** ← ارجع ← **تثبيت**.
3. نسخة يونيتي اسمها **Duskwell Unity** وتُثبّت **بجانب** اللعبة الأصلية لا مكانها (معرّفها مختلف: `com.duskwell.unity`).

## إن واجهتك مشكلة

| المشكلة | الحل |
|---|---|
| Hub يقول إن نسخة المحرّر غير مثبّتة | ثبّت 2022.3.62f1 من الأرشيف (الخطوة 4)، أو اختر أي 2022.3 مثبّتة ثم **Continue** |
| لا يوجد خيار Android في Build Settings | Unity Hub ← **Installs** ← ⚙ بجانب النسخة ← **Add modules** ← علّم Android Build Support مع OpenJDK و SDK & NDK |
| أخطاء عن JDK أو SDK أو Gradle عند البناء | **Edit ← Preferences ← External Tools**: علّم كل الخيارات التي تنتهي بـ **installed with Unity** |
| أخطاء عن طول المسار (Path too long) | انقل المجلد إلى مسار أقصر مثل `C:\D\duskwell-unity` وأعد إضافته في Hub |
| يونيتي بطيء جداً أو يتوقف | أغلق البرامج الأخرى؛ الفتح الأول طويل طبيعياً |
| لا صوت أثناء اللعب في المحرّر | في أعلى تبويب Game تأكّد أن زر **Mute Audio** غير مفعّل |
| الأزرار لا تستجيب | اضغط داخل نافذة Game مرة ثم جرّب المفاتيح |
| تريد البدء من جديد | من شاشة العنوان اختر **رحلة جديدة** (يمسح الحفظ) |
| أي خطأ أحمر في Console | صوّره وأرسله لي |

## ما في المشروع

| المجلد / الملف | ماذا فيه |
|---|---|
| `Assets/Scripts/Game.cs` | الغرف، البطل وحركته، الكاميرا، الوحوش، الزعماء، الصوت، الحفظ |
| `Assets/Scripts/StoryText.cs` | القصة كاملة: المقدّمة، النهاية، المناطق، الزعماء، الذكريات، كلام الشخصيات |
| `Assets/Scripts/StoryUI.cs` | شاشة العنوان، مشاهد القصة، الحوار، المتجر، البطاقات، وعاء الروح |
| `Assets/Scripts/World.cs` | الألغاز (جدران، روافع، بوابات، أرض تتفتت، أرض مشقوقة)، المقاعد، الكنوز، القدرات، الروح |
| `Assets/Scripts/Fight.cs` | قاعات الزعماء، حركاتهم الخاصة، الحرّاس المتوسطون، الطلقات |
| `Assets/Scripts/Arabic.cs` | وصل الحروف العربية وكتابتها من اليمين |
| `Assets/Editor/Build.cs` | زر **Duskwell ← Build Android APK** وإعدادات استيراد الصور والأصوات |
| `Assets/Resources/` | كل الرسومات (159 غرفة، الوحوش، الزعماء، الشخصيات، لوحات القصة) والموسيقى والأصوات والخط |
