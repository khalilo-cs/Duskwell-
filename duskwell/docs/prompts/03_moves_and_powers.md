# Special moves and hero powers

Effect sheets. Each effect is drawn alone (no hero in it) on the plain grey background, so the game can place it on any character.

## Move: Moon Rend (`rend`)
```
glowing effect art, same painted look. Dark hand-painted 2D game art for a side-scrolling action-exploration game: moody, slightly desaturated palette with one glowing accent colour, clean thin dark ink outline of even weight, soft painted shading from a single light source at the top-left, rim light on the edge facing the light, readable silhouette at small size. Side view, character faces RIGHT. Original design, not a copy of any existing game or character.
Effect animation sheet "Moon Rend": a huge crescent shock-wave of pale silver-blue light that flies forward from the nail and widens as it goes.
Row 1: start (4 frames). Row 2: main loop (6 frames, seamless). Row 3: impact / end (6 frames, fades out).
Bright core, soft outer glow, a few flying sparks; no character, no ground.
One image. A plain flat mid-grey background (#808080), perfectly even: no gradient, no floor, no cast shadow, no vignette, no text, no labels, no frame lines, no watermark. Every drawing sits in its own invisible cell of a regular grid with clear empty grey space around it, never touching or overlapping another. All drawings in the sheet are the SAME SCALE (the body never gets bigger or smaller between frames) and share the same ground line: feet / lowest point of the body on the same baseline in each row. Same character, same colours, same proportions in every frame. High resolution (at least 2048 px wide).
```
