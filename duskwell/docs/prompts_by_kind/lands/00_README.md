# الأراضي: البلاطات والجدران والمنصات والمخاطر والزينة والخلفيات

مجلد لكل منطقة من المناطق الخمس عشرة، وفيه عشرة برومبتات:
1. بلاطات الأرض (حشوة، سطح يُمشى عليه، سقف، حواف، زوايا) بمقاس 64×64 بكسل تتصل ببعضها بلا فواصل.
2. الجدران والأبواب والبوابات والجدران القابلة للكسر.
3. المنصات (رفيعة، متهاوية، متحركة).
4. المخاطر (أشواك، سائل المنطقة، منشار، صواعد تسقط).
5. زينة واقفة.
6. زينة معلّقة.
7–9. ثلاث طبقات خلفية (بعيدة، وسطى، قريبة) تتكرّر أفقياً بلا فواصل.
10. لوحة غرفة كاملة كمرجع للجو.

وفي `00_common/` قطع مشتركة بين كل المناطق: المقعد ومحطة الفانوس والرافعة والصناديق واللافتات وعملات الجيو والكتابات المرشدة.

طريقة الاستعمال: كل برومبت جاهز للنسخ كما هو، والأسلوب والمواصفات التقنية مكتوبة داخله.
المطلوب في كل صورة **شريط واحد خام على خلفية رمادية موحّدة بلا أي نص ولا عناوين ولا لوحات**، وليس «لوحة عرض».
ابدأ بالصورة المرجعية للشخصية، ثم أرفقها مع كل برومبت بعدها حتى يبقى التصميم ثابتاً.
لا تستعمل تصاميم أو أسماء من ألعاب أخرى. بعد أن تصنع الصور أرسلها لي فأقصّها وأربطها باللعبة.
